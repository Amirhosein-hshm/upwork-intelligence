## ۳. مراحل Setup قدم‌به‌قدم

### مرحله ۰: تأیید حقوقی و محل (قبل از همه)
- [ ] تأیید کنید که حساب Upwork **به‌صورت قانونی** برای شما قابل استفاده است.
- [ ] اگر پاسخ منفی است، پروژه را روی منبع دیگری (که شما مجازید) بازتعریف کنید؛ این فایل‌ها را همچنان می‌توان استفاده کرد.

### مرحله ۱: Gmail و فیلتر
1. یک Gmail اختصاصی بسازید یا از ایمیل موجود استفاده کنید؛ **Upwork Alerts را روی همین ایمیل تنظیم کنید** (Notification Settings → Email updates / Job alerts).
2. Gmail → Settings → Filters → Create:
   - From: `upwork.com` (و `upwork-email` یا آدرس‌های ایمیل رسمی که در ایمیل‌ها می‌بینید)
   - Apply label: `Upwork`
   - Skip the Inbox (اختیاری)
3. ۵ ایمیل Alert را به‌صورت sanitized (بدون نام/ایمیل/شماره) ذخیره کنید؛ این‌ها fixture تست parser هستند.
4. 2-Step Verification را فعال کنید → App Password بسازید (نام: `upwork-agent`). **کلید را هرگز در چت یا Git قرار ندهید.**

### مرحله ۲: Telegram
1. در Telegram با @BotFather: `/newbot` → نام و username → **توکن** را در `.env` ذخیره کنید.
2. یک گروه بسازید (فقط خودتان یا تیم). بات را اضافه کنید.
3. در @BotFather: `/setprivacy` → `Disable` (تا بات دستورات گروه را ببیند؛ یا از `/command@botname` استفاده کنید).
4. یک پیام تستی در گروه بفرستید، سپس در مرورگر:
   `https://api.telegram.org/bot<TOKEN>/getUpdates` → `chat.id` گروه (عدد منفی) را بردارید.
5. (اختیاری) ساخت یک Telegram Bot برای alert مدیریتی جدا.

> **هشدار ایران:** تلگرام در ایران مسدود است؛ برای خواندن پیام‌ها نیاز به VPN دارید. این موضوع با ۱۰۰٪ تضمین نیست؛ اگر دسترسی ندارید، fallback ایمیل را در فاز ۲ اضافه کنید.

### مرحله ۳: کلیدهای LLM
1. **Google AI Studio** → Get API key (فقط اگر منطقه‌ی شما مجاز است).
2. **Groq** → API key (بررسی شرایط کشور).
3. **OpenRouter** → Key؛ بعد از ~$۱۰ شارژ یک‌باره، سقف روزانه‌ی free از ۵۰ به ۱۰۰۰ می‌رود (منابع ثالث؛ تأیید در تنظیمات شما).
   - تنظیم Privacy: گزینه‌ی «may train on prompts» را برای مدل‌های رایگان خاموش کنید.
4. **Ollama** (اختیاری): نصب و `ollama pull <model>` (نام مدل را از کتابخانه‌ی رسمی Ollama بررسی کنید).
5. کلیدها را در `.env` قرار دهید:
   ```bash
   GEMINI_API_KEY=...
   GROQ_API_KEY=...
   OPENROUTER_API_KEY=...
   TELEGRAM_BOT_TOKEN=...
   TELEGRAM_CHAT_ID=-100...
   IMAP_HOST=imap.gmail.com
   IMAP_USER=you@gmail.com
   IMAP_APP_PASSWORD=...
   IMAP_LABEL=Upwork
   ```
   و `chmod 600 .env`.

### مرحله ۴: سرور
- **گزینه‌ی خانگی:** Ubuntu/Debian روشن، `uv` نصب، Ollama (اختیاری).
- **گزینه‌ی VPS:** ساخت سرور با SSH key (نه رمز)، فایروال (فقط SSH)، کاربر غیر-root، به‌روزرسانی امنیتی خودکار.
- ریپو را Clone کنید؛ `profile/` و `.env` را **محلی** بسازید (در Git نیستند).

### مرحله ۵: systemd timer (نمونه)
```ini
# /etc/systemd/system/upwork-agent.service
[Unit]
Description=Upwork alert agent (one run)
[Service]
Type=oneshot
User=agent
WorkingDirectory=/opt/upwork-intelligence
EnvironmentFile=/opt/upwork-intelligence/.env
ExecStart=/usr/bin/env uv run python -m src.main run-once
```
```ini
# /etc/systemd/system/upwork-agent.timer
[Unit]
Description=Run upwork agent every 5 minutes
[Timer]
OnBootSec=2min
OnUnitActiveSec=5min
Persistent=true
[Install]
WantedBy=timers.target
```
```bash
sudo systemctl enable --now upwork-agent.timer
journalctl -u upwork-agent.service -n 100 --no-pager
```

### مرحله ۶: تست و معیار پذیرش
- [ ] ۵ ایمیل sanitized → ۵ JSON معتبر.
- [ ] یک پیام تلگرام تست با HTML و `<pre>` سالم نمایش داده شود.
- [ ] اجرای دوباره روی همان ایمیل → پیام تکراری نیست.
- [ ] Kill provider اصلی (کلید اشتباه) → fallback کار کند.
- [ ] `git status` هیچ فایل `.env`، `profile/`، `data/` را نشان ندهد.
